# 定時フォト転送（iOS以外のスマホ用アプリ）配布

同じ Wi-Fi の端末どうしで、写真を決まった時刻や Wi-Fi 接続時に自動で送るアプリ「定時フォト転送」の配布用リポジトリです。
ソースコードは含まれていません。
